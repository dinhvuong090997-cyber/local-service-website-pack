# Local Service Website Pack

This is a sellable static one-page website demo for small local service businesses.

The demo business is `FixFast Repair`, a fictional phone and laptop repair shop.

## Preview

Open `index.html` in a browser.

No build step is required.

## Files

- `index.html`: page content and buyer-editable business details
- `styles.css`: responsive layout and visual design
- `script.js`: mobile navigation and current year
- `SALES_KIT.md`: posts, messages, gig copy, and client checklist

## Customize For A Client

Edit these parts in `index.html`:

- Business name
- Hero headline
- Services
- Starting prices
- Phone number
- WhatsApp link
- Map or service area link
- Opening hours

Search for:

```text
FixFast
+1 (555) 010-1444
Downtown and nearby suburbs
```

Replace those with client details.

Do not share bank login, card details, passwords, OTP codes, or payout credentials with anyone. The seller should receive payment through their own platform account.
